# Child Agent Runtime Distribution Plan

This plan owns child-agent package distribution: Windows, macOS, Linux, Android, and iOS artifacts, respawn, tamper/uninstall proof, signing/device-owner matrix, and setup-device-trust handoff.

It keeps the historical parent-client route separate. Parent client distribution lives in `docs/plans/parent-desktop-runtime-package-plan/` for compatibility and canonical meaning `parent-client-runtime-distribution-plan`.
