# Parent Client Runtime Distribution Plan

This plan owns parent client distribution: web portal, desktop shell/package, Android app/package, iOS app/package, route bridge contracts, signing/notarization/store claims, update/rollback, release artifacts, launch smoke, and platform capability matrix.

It keeps the historical `docs/plans/parent-desktop-runtime-package-plan/` path for compatibility, but the canonical scope is parent client runtime distribution. Child agent runtime/package distribution is a separate plan.
