# Account Identity Family Plan

This plan owns identity and household authority: login, registration, users, parent/child/co-parent roles, invites, sessions, auth provider choice, account recovery, device ownership, cross-family authorization, and the first-run parent family setup UI.

It does not own public website content, installer/package mechanics, child-data storage, policy authoring, or remote transport. Those are handoffs.

Start with [AGENTS.md](AGENTS.md), then the selected workpack, then [PROOF_AND_TEST_INVENTORY.md](PROOF_AND_TEST_INVENTORY.md) when proving a slice.
