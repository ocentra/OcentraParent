This plan owns the parent policy control plane: parent intent, typed policy source of truth, preview, approval, delivery, domain compilers, enforcement handoff, audit, schedules, exceptions, and ask-parent flows.

It does not own each domain adapter. App/game, browser, network, tracking, screen, and enforcement plans own their own runtime effects.
