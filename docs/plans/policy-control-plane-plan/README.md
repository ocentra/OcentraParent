# Policy Control Plane Plan

This plan owns the parent policy control plane: typed policy source of truth, lifecycle, preview, approval, delivery, domain compilers, enforcement handoff, audit, schedules, exceptions, ask-parent flows, and policy event semantics.

It does not own each domain adapter. App/game, browser, network, tracking, screen, and enforcement plans own their own runtime effects.
