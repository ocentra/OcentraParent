# Ocentra Parent Feature List

This is the unified feature index. It is the first file to open when deciding
what Ocentra has, what is planned, what competitors do, and what the next AI
agent should work on.

Status words come from [Product Constitution](product-constitution.md). The
cross-feature status table is
[Product Capability Checklist](product-capability-checklist.md). Competitor
baseline is [Competitor Capability Map](competitor-capability-map.md).

## Required Shape For Each Feature Doc

Each file under `docs/features/` must include:

- parent outcome;
- Ocentra product requirement;
- roadmap and expectation links;
- competitor pressure;
- current Ocentra state;
- current gap;
- checklist;
- next AI instructions.

If a feature changes, update this index, the feature doc, the matching
expectation docs, and the product capability checklist in the same pass.
