- duplicated_shapes: Strong overlap remains with `packages/policy-domain/src/policy.ts`, `policy-event.ts`, `authority.ts`, and `policy-compiler.ts` for IDs, status enums, and event scopes.

- event_log_proof_misuse: No direct misuse observed, but redacted summaries should stay summary-only if future logging is added so source and request payloads do not leak into proof chains.
- test_proof_structure_issues: The crate's current layout encourages duplicated per-subarea tests rather than one clean owner for primitive policy identifiers and shared status shapes.
- dry_score_0_to_100: 49

- decouple_recommendation: Pull primitive policy shapes into a smaller shared core and leave source/request/preview/delivery workflow modules to build on top of it.
- blockers: Audit-only refresh; no code changes are being made, so the exact consumer map and downstream replay/validation impact should be rechecked before any split.
