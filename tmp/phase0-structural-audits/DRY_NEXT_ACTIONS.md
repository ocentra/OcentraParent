## No-Reexport Coordination Standard
- Re-exports/barrels are banned and must not be replaced with new re-export or compatibility shims.
- Forbidden shapes: Rust `pub use`, `pub(crate) use`, `pub(super) use`; TypeScript `export *`, `export { X } from`; alias re-export files; root frontage barrels; barrel-like hop modules.
- Acceptable cleanup shape: direct imports from the owning source module.
- Rust public access shape: expose the owning module itself with `pub mod owning_module;`, then import `crate::owning_module::Thing` or external `crate_name::owning_module::Thing` directly.
- If a packet cannot avoid a shim or re-export within the path cap, report BLOCKED or provide a split plan rather than adding debt.
