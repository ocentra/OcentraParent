# Manual Platform Proof

WP34 uses the local Windows service capture path in automated Rust tests. It
does not claim a manual platform tier beyond bounded live process observation.

Manual/platform gaps remain:

- recurring service polling and freshness status;
- foreground window capture for app/game rows;
- installed inventory crawling;
- policy/runtime consumption;
- adapter execution and rollback proof;
- macOS/Linux/Android/iOS parity.
