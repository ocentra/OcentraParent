# AI-23 Security Negative Proof

Rejected or non-claimed states:

- unmanaged social URLs cannot become exact social route evidence;
- social post route rows require a visible post id;
- dynamic-feed TTL stale memory rows cannot drive policy input;
- stale dynamic-feed memory rows claiming policy-input authority are rejected;
- live proof output rejects generated or fixture pages as final evidence;
- live proof output rejects persisted raw HTML, title text, and description
  text;
- URL route shape rows cannot claim feed recommendation semantics;
- URL route shape rows cannot claim account identity proof;
- URL route shape rows cannot claim messaging/contact analysis;
- URL route shape rows cannot claim upload monitoring;
- URL route shape rows cannot claim livestream content analysis;
- URL route shape rows cannot claim AI decisions, policy decisions, or direct
  policy authority.

Security boundary:

AI-23 parses already-captured managed exact URLs into typed route evidence. It
does not persist page bodies, child sessions, cookies, messages, contacts,
uploads, livestream media, platform feeds, credentials, connector payloads, or
native app routes. The live harness fetches public route surfaces only to prove
the route is real and to derive redacted response hashes/statuses for the exact
URL parser proof.
