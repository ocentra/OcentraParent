# SOCIAL-22 Security Negative Proof

SOCIAL-22 rejects social audit/explanation overclaims:

- runtime audit store;
- rendered explanation UI;
- notification delivery;
- raw account data;
- raw video content;
- raw message content;
- connector authorization;
- native app control;
- final policy decisions;
- enforcement.

The contracts describe ref-only audit/explanation rows. They do not persist a
runtime audit store, render pages, send notifications, store raw content,
authorize connectors, control native apps, decide final policy, or execute
enforcement.
