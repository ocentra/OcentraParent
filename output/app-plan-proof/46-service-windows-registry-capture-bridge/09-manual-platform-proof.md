# WP46 Manual Platform Proof

WP46 does not claim manual platform support.

Registry service capture proves that bounded Windows Uninstall registry native
app inventory events can pass through the service journal/store path. It does
not prove AppLocker, App Control, MDM, Endpoint Security, Device Owner/Profile
Owner, FamilyControls/ManagedSettings, cgroup/systemd, kiosk/single-app, or any
other platform enforcement adapter behavior.
