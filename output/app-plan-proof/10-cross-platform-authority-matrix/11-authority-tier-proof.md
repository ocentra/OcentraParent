# Authority Tier Proof

Native app WP10 uses the shared authority tiers:

- observe-only
- user-approved-helper
- accessibility-assisted
- managed-profile
- device-owner
- mdm-enrolled
- supervised-device
- system-extension
- root-or-admin-service
- kiosk-or-single-app
- manual-required
- not-claimed

Every native app action row can name platform, authority tier, setup state,
proof state, capability state, parent-visible limitation, proof references, and
proof needed to claim.
