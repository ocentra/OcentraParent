# Native App Approval Contract Proof

This proof records the app-plan WP16 mirror of the shared app/game WP17
contract implementation.

Native app states covered:

- New inventory app candidate.
- Unknown runtime process candidate.
- Portable executable candidate.
- Installer/updater candidate.
- Parent response scope for allow once, allow this app/game, ask child why,
  deny, report-only, and block-if-supported.
- Expiry, audit-backed replay, storage-unavailable, and manual-required block
  states.

Native app no-claim boundary:

- The contract can represent approval requests and safe outcomes.
- It does not prove OS candidate discovery, notification delivery, child
  request UX, parent approval UI, service storage, or platform hard-block
  authority.
