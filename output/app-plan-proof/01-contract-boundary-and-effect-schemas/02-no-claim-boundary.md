# No-Claim Boundary

This proof does not claim a live installed-app inventory adapter, process or
foreground capture, production event-bus publisher/consumer, journal/SQLite
storage, service read model, AI classification result, policy evaluation,
adapter dispatch, enforcement, portal rendering, or platform capability parity.

The schema-domain module is an edge decoder for the Rust-owned app-core event;
it does not become a native-app runtime owner.

The code graph currently shows only test callers for
`app_runtime_decision_recorded_event` and `app_runtime_observed_event`. This
contract slice therefore does not claim production runtime wiring or full WP01
completion. Any live source/publisher/consumer work requires an explicit
app-game-plan app-only handoff.
